#  Wpf_PueblosCLM

Aplicación WPF que lee el JSON de un CSV guardado en [Google Drive](https://docs.google.com/spreadsheets/d/1gunIZh6PPvNRC37QH1YqXEH1HzEWWZrY/edit?gid=1060052662) con los pueblos de Castilla-La Mancha y los mete en un ComboBox.

**Requiere [.NET 7.0](https://dotnet.microsoft.com/en-us/download/dotnet/7.0)**
